# Miorbi 0.1.1 Beta 3 — Menu-bar safe layout

## 简体中文

- 菜单栏高度内只贴合物理刘海，不向两侧扩张黑底或放置文字。
- Codex 状态与限额保持常显，移至刘海下方的紧凑状态条。
- 鼠标悬停的控制区只在菜单栏下方展开；两侧原有菜单仍可点击。
- 无刘海屏幕不显示顶部浮层，通过 Miorbi 菜单栏图标的「打开面板」使用。
- 保留 Beta 2 精修透明图标、专注/宠物、音乐功能。

macOS 14+。Apple 芯片选 arm64，Intel 选 x86_64。公开包为 ad-hoc 签名，未经 Apple 公证。核对 SHA256SUMS.txt，若可信且被拦截，可使用系统设置中的「仍要打开」，不要关闭全局 Gatekeeper。

已知限制：未实测所有外接屏组合；Apple Music 同步歌词未实现；网易云数据读取需系统权限，歌词与限额同步默认关闭；不承诺零延迟。Codex 完成判定仍使用安静期启发式。

## English

The menu-bar band paints only the physical notch; it no longer extends into system menus. Persistent Codex activity/limits now sit below the notch. Hover controls expand below the menu bar. Unnotched displays use the menu-bar Open panel command instead of a top overlay. Retains Beta 2 refined transparent branding and focus/music features.

macOS 14+. Choose arm64 for Apple silicon or x86_64 for Intel. Ad-hoc signed, not notarized. Verify SHA256SUMS.txt and, only if trusted, use the per-app Open Anyway option; do not disable Gatekeeper globally.

Limitations: all external-display combinations have not been tested; Apple Music synced lyrics remain unimplemented; NetEase data access requires permission; lyric/usage sync is off by default; zero latency is not guaranteed. Completion uses a quiet-period heuristic.
