# Miorbi 0.1.1 Beta 7 — Organized settings

设置改为五个独立页面：Codex 状态、歌词、专注、我要吐槽、关于软件。语言切换、版本、构建和许可位于关于页。各页面只显示自己的设置；原有选项、累计时间和权限没有重置。

Settings now have five separate pages: Codex status, Lyrics, Focus, Feedback and About. Language, app version, build and license live in About. Existing preferences, focus credits and permissions are retained.

macOS 14+。公开测试包采用 ad-hoc 签名、未经 Apple 公证。核对 SHA256SUMS.txt；只对可信应用使用系统设置中的“仍要打开”，不要关闭全局 Gatekeeper。

macOS 14+. Ad-hoc signed, not notarized. Verify SHA256SUMS.txt and use per-app Open Anyway only if trusted; never disable Gatekeeper globally.

保留 Beta 6 功能及限制：Apple Music 同步歌词未实现；网易云歌词及限额同步默认关闭、需要各自授权；拥挤菜单栏可能重叠；不保证零延迟或所有设备组合兼容。

Retains Beta 6 features and limitations: Apple Music synced lyrics remain unimplemented; NetEase lyrics and usage sync are off by default and require their own authorization; crowded menu bars may overlap; zero latency and universal device compatibility are not guaranteed.
