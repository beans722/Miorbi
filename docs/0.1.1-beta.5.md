# Miorbi 0.1.1 Beta 5 — Adaptive focus controls

## 简体中文

空闲悬停时专注控件与物理刘海同宽，使用紧凑“开始”和时长按钮。Codex 或音乐活动时按紧凑活动宽度展开，不再额外加宽。Codex 的宠物、状态、限额仅保留顶部一组；展开区不重复显示。音乐控制保留一组。限额不可用时显示破折号，不伪装成完成状态。

macOS 14+。Apple 芯片选择 arm64，Intel 选择 x86_64。公开包为 ad-hoc 签名，未经 Apple 公证。核对 SHA256SUMS.txt；仅对可信来源的软件使用系统设置“仍要打开”，不要关闭全局 Gatekeeper。

保留 Beta 4 其他功能及限制：非常拥挤的菜单栏可能仍重叠；网易云歌词与限额同步默认关闭、需要权限；Apple Music 同步歌词未实现；不保证零延迟或所有外接屏组合兼容。

## English

Idle hover focus controls now match the physical notch width. Active Codex/music controls use the same compact activity width without extra widening. Codex pet/status/limits appear only once in the top row; music controls also have one group. Unavailable limits use dashes rather than a completion checkmark.

macOS 14+. Download arm64 for Apple silicon or x86_64 for Intel. Ad-hoc signed and not notarized; verify SHA256SUMS.txt and use per-app Open Anyway only if trusted. Never disable Gatekeeper globally.

Retains Beta 4 features and limitations: crowded menu bars may overlap; lyric/usage sync is off by default and requires permissions; Apple Music synchronized lyrics are unimplemented; no guarantee of zero latency or every display configuration.
