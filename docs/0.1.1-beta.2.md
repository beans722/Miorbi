# Miorbi 0.1.1 Beta 2 — Refined Lyric Focus

## 简体中文

菜单栏重新精修，保留定稿图标的断开计时弧、内层灵动岛胶囊、两行长短歌词和右下三个刻度。透明底、系统自动着色，不再使用深色方块，也不再简化成普通三条线。App 与设置继续使用完整彩色图标。

macOS 14+。Apple 芯片下载 arm64，Intel 下载 x86_64，拖入 Applications。测试包为 ad-hoc 签名，未经 Apple 公证，可能需在系统设置 → 隐私与安全性中选择「仍要打开」。先核对 SHA256SUMS.txt，不要关闭全局 Gatekeeper。

其他功能延续 Beta 1：Codex 状态/限额、透明网易云歌词、专注计时/宠物和中英设置。限额与网易云歌词默认关闭；启用时需本机凭据或数据授权。Apple Music 同步歌词未实现，不承诺零延迟或所有设备兼容。完成判定使用安静期启发式。

## English

Refined transparent menu-bar artwork preserves the broken focus contour, inner island capsule, two lyric strokes and three lower-right ticks from the selected full-color icon. Uses automatic system tint with no dark tile. The app and settings retain the full-color artwork.

Requires macOS 14+. Download arm64 for Apple silicon or x86_64 for Intel and drag to Applications. Test builds are ad-hoc signed and not notarized. Verify SHA256SUMS.txt; if blocked and trusted, use the per-app Open Anyway option. Never disable Gatekeeper globally.

Retains Beta 1 features. Usage sync and NetEase lyrics are off by default and require local credentials/data permission when enabled. Apple Music synced lyrics are not implemented; zero latency and all-device compatibility are not guaranteed. Completion detection uses a quiet-period heuristic.
