# Miorbi 0.1.1 Beta 9 — Stale session recovery

修复缺少 Stop 的会话被当作运行中长达两小时的问题。按会话与轮次核对本地线程状态、原生生命周期结束记录和最近日志更新。没有可靠运行证据、没有新进展的记录，在用户选择的 5/10 分钟后失效，不再卡住动画与额度。原生结束事件可以补足缺失的 hook；有当前轮次近期进展的长任务保留运行态。旧会话不再遮住其他任务的结束状态，新事件仍可唤醒。

只读本地 Codex 状态与日志生命周期元数据，不写 Codex 数据库、不保存或上传对话正文、不发起模型请求。日志尾部读取有大小上限并按修改时间缓存。本地格式不受官方兼容承诺保障；无法读取或核实时使用有界超时兜底，而不是伪造任务完成。没有日志进展的真实长任务也可能被隐藏，原 Codex 任务本身不会被暂停或终止。

Fixes missing-Stop records appearing active for two hours. Checks exact local turn status, native terminal lifecycle metadata and recent matching-log progress. Unverified records without progress expire after the selected 5/10 minutes; native completion can recover a lost hook; recent matching progress keeps long tasks visible. Old sessions no longer mask other completions, and new events wake the display.

Read-only local metadata, no database changes, no conversation storage/upload and no model requests. Bounded cached log-tail reads. Local formats are not guaranteed stable; unavailable verification falls back to expiry, never fabricated completion. A real task with no observable progress may also be hidden, but Miorbi does not pause or terminate that task.

macOS 14+。公开测试包为 ad-hoc 签名、未经 Apple 公证。核对 SHA256SUMS.txt，只对可信应用使用“仍要打开”，不要关闭全局 Gatekeeper。保留先前歌词和菜单栏兼容限制。
