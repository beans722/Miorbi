# Miorbi 0.1.1 Beta 1

## 简体中文

- 统一 App、菜单栏、设置和安装包的「灵动岛＋歌词＋专注」图标。
- 紧凑刘海与平滑悬停展开；透明歌词在音乐播放时显示。
- Codex 活动与限额在任务运行时显示；停止后隐藏限额，完成提示经过安静期去重。
- 网易云同步歌词测试接入；专注计时、宠物和中英设置保留。

macOS 14 或更新版本。Apple silicon 下载 arm64，Intel 下载 x86_64，拖入 Applications。公开测试包为 ad-hoc 签名，未经 Apple 公证，不能保证无安全提示。先核对 SHA256SUMS.txt；首次打开被拦截时，确认可信后使用系统设置 → 隐私与安全性 → 仍要打开。不要关闭全局 Gatekeeper，也不要对未知来源软件强制重新签名。

本机数据权限和系统授权仍需用户手动授予。限额同步默认关闭，开启后读取本机 Codex access token，仅请求 ChatGPT 用量接口。网易云歌词默认关闭，开启后只向 music.163.com 发送歌曲 ID，无账号/Cookie。无分析统计或自动上传日志。

已知限制：Apple Music 同步歌词未实现；网易云数据格式可能随播放器更新失效；完成判定是安静期启发式；未验证所有设备和零延迟歌词。

## English

Unified Lyric Focus artwork across the app, menu bar, settings and packages. Updated compact notch, hover focus controls, transparent playback lyrics, Codex activity/limits and quota hiding after Stop. Experimental NetEase synced lyrics, focus pets and bilingual settings.

Requires macOS 14+. Choose arm64 for Apple silicon or x86_64 for Intel; drag to Applications. Public test packages are ad-hoc signed, not notarized. Verify SHA256SUMS.txt and, only if trusted, use the per-app Open Anyway option under Privacy & Security. Never disable Gatekeeper globally or force-sign unknown software.

User permissions are still required. Usage sync is off by default and sends the local Codex access token only to the ChatGPT usage endpoint. NetEase lyrics are off by default and send only song IDs to music.163.com without accounts/cookies. No analytics or automatic log upload.

Known limitations: Apple Music synced lyrics are not implemented; NetEase local data formats may change; completion detection uses a quiet-period heuristic; universal device compatibility and zero-latency lyrics are not verified.
